# 代码组织

当前程序导入 Git 仓库、画出提交图谱、搜索和筛选历史、自动刷新、查看完整提交信息与文件历史、比较任意两个分支或哈希，查看工作区相对 HEAD 的未提交改动，从远程 fetch，并在提交行右键添加标签、新建分支或修改说明。`docs/` 里更早的 P0 / P1 文档是上一版完整客户端的记录，不代表现在的范围。

## 目录

| 路径 | 职责 |
|---|---|
| `go.mod` | 模块在仓库根。 |
| `cmd/gitclient/` | 桌面程序，`package main`。`mygo.json`、图标和 `go tool mygo` 都在这里。 |
| `docs/` | 历史需求、目录说明和演进计划。 |
| `docs/演进计划.md` | 项目演进的决策总纲：模块索引、候选账本、排期；模块计划写在 `docs/差异视图计划.md`、`docs/Git执行计划.md`、`docs/worktree计划.md`、`docs/历史列表计划.md`。 |

界面和 Git 读取仍是一个 `main` 包。字段不多，拆包只会把 `app` / `repoTab` 全部导出。

| 文件 | 放什么 |
|---|---|
| `main.go` | 窗口、隐藏标题栏、导入页、提交表和图谱绘制 |
| `menu.go` | macOS 瘦菜单；Windows/Linux 不设菜单栏 |
| `graph.go` | 泳道布局。已排过的提交不因后续翻页改列 |
| `model.go` | 提交、仓库标签、最近仓库 |
| `repo.go` | 打开、刷新、取消、翻页和定位提交 |
| `history_pager.go` | 按需读取同一条 Git 流，后台准备图谱与提交索引 |
| `history_cache.go` | 后台仓库缓存预算和阅读位置恢复 |
| `repo_scan.go` | 复用目录扫描结果，发现新增或删除的嵌套仓库 |
| `git.go` | 系统 Git：仓库根、提交流、引用、提交改动和比较 |
| `write.go` | 添加标签、新建分支、修改说明 |
| `write_ui.go` | 提交行右键菜单和写操作对话框 |
| `fetch.go` | 获取全部远程，可选 prune |
| `compare.go` | 单击提交详情、比较对话框、两点选提交、文件列表和只读 diff |
| `file_tree.go` | 改动文件的树状视图、紧凑文件夹 |
| `history_query.go` | 搜索、分支范围、固定分页起点与返回阅读位置 |
| `refresh.go` | 活动仓库引用检查、前台刷新和自动 fetch |
| `ref_watch.go` | 引用目录与 packed-refs / reftable 的轻量变化检查 |
| `commit_details.go` | 按需读取完整提交信息、展开和复制 |
| `file_history.go` | 按版本追踪文件历史、重命名分页和返回图谱 |
| `icons.go`、`icons/` | Lucide 工具栏图标（ISC） |
| `worktree.go` | 工作区未提交改动 |
| `dialog.go` | 选择仓库目录 |
| `*_test.go` | 与被测文件放在一起，继续用 `package main` |

新的图谱能力放进这些文件。独立能力再加文件。提交行上目前只开放添加标签、新建分支和修改说明，不要顺手恢复其余写操作或设置。

## 常用命令

```sh
CGO_ENABLED=0 go test ./cmd/gitclient
```

在 `cmd/gitclient/`：

```sh
go tool mygo vet .
go run . /path/to/repository
```
